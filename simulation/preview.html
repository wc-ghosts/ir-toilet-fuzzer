IR Fuzz Compare 0.17

Sniff mode → capture → choose a label → save on SD and choose a maker. Profiles use automatic names such as TOTO 003. Capture sets / diff also has Save profile, using the same maker picker. Remove duplicates is an explicit profile action. Load profile → choose a named signal → fuzzer, analysis or original replay. Quick single-signal capture and the existing range editor remain available. More options includes an INAX command-inversion edit. TOTO retains its prefix and offers XOR repair. INAX retains its first byte and can maintain a captured inverse pair. Advanced protocol analysis remains optional. Saved-signal matching is passive. Live sending waits 1–2 seconds after each packet; OK pauses and saves the exact emitted waveform.

Shapes, positions, labels and selection come from draw calls in the actual C renderer. Fonts and LCD colours are approximate. These are recorded screens, not a device emulator; the terminal simulator runs the actual button handlers. No physical IR was emitted.
